# Quarto data science portfolio starter

A small Quarto website designed for GitHub Pages.

## Preview locally

1. Install [Quarto](https://quarto.org/docs/get-started/).
2. In this folder, run:

   ```bash
   quarto preview
   ```

3. Quarto opens a local preview in your browser.

To generate static website files:

```bash
quarto render
```

The generated site is written to `_site/`.

## Publish with GitHub Pages

1. Create a public repository named `scottsiegers.github.io` (replace with your exact GitHub username).
2. Push these source files to the repository.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **GitHub Actions**.
5. Add a Quarto publishing workflow. Quarto's official guide:
   https://quarto.org/docs/publishing/github-pages.html

The starter uses sample copy and placeholder links. Update the project descriptions, contact details, and GitHub links before publishing.
